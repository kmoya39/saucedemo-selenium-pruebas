## CP-09 Cerrar sesión desde el menú lateral

| Campo | Detalle |
|---|---|
| Módulo | Autenticación |
| Tipo de prueba | Funcional y de seguridad |
| Prioridad | Alta |
| Técnica de diseño | Transición de estados (sesión activa a sesión cerrada) |
| Precondición | Sesión iniciada con standard_user. |
| Datos de prueba | Ruta de acceso directo: /inventory.html |
| Script automatizado | `pruebas/test_inventario.py::test_cerrar_sesion` |

### Pasos
1. Abrir el menú lateral
2. Presionar Logout
3. Intentar abrir /inventory.html directamente

### Resultado esperado
Se vuelve al login y el acceso directo al inventario se bloquea con un mensaje que exige iniciar sesión.

## CP-02 Inicio de sesión con contraseña incorrecta

| Campo | Detalle |
|---|---|
| Módulo | Autenticación |
| Tipo de prueba | Funcional (negativa) |
| Prioridad | Alta |
| Técnica de diseño | Partición de equivalencia (clase inválida) y tabla de decisión |
| Precondición | El sitio está disponible y no hay sesión iniciada. |
| Datos de prueba | Usuario: standard_user; contraseña: clave_incorrecta |
| Script automatizado | `pruebas/test_login.py::test_inicio_sesion_contrasena_incorrecta` |

### Pasos
1. Abrir la página de inicio de sesión
2. Escribir el usuario válido y una contraseña incorrecta
3. Presionar Login

### Resultado esperado
Se muestra el mensaje Epic sadface: Username and password do not match any user in this service y se permanece en el login.

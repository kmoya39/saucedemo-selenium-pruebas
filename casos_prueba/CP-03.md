## CP-03 Inicio de sesión con usuario bloqueado

| Campo | Detalle |
|---|---|
| Módulo | Autenticación |
| Tipo de prueba | Funcional (negativa) |
| Prioridad | Alta |
| Técnica de diseño | Tabla de decisión (usuario existente, contraseña correcta, cuenta bloqueada) |
| Precondición | El sitio está disponible y no hay sesión iniciada. |
| Datos de prueba | Usuario: locked_out_user; contraseña: secret_sauce |
| Script automatizado | `pruebas/test_login.py::test_inicio_sesion_usuario_bloqueado` |

### Pasos
1. Abrir la página de inicio de sesión
2. Escribir el usuario bloqueado y la contraseña
3. Presionar Login

### Resultado esperado
Se muestra el mensaje Epic sadface: Sorry, this user has been locked out.

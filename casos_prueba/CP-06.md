## CP-06 Ordenar productos por precio de menor a mayor

| Campo | Detalle |
|---|---|
| Módulo | Catálogo y carrito |
| Tipo de prueba | Funcional |
| Prioridad | Media |
| Técnica de diseño | Partición de equivalencia (opción de orden lohi) |
| Precondición | Sesión iniciada con standard_user. |
| Datos de prueba | Opción de orden: Price (low to high) |
| Script automatizado | `pruebas/test_inventario.py::test_ordenar_precio_menor_mayor` |

### Pasos
1. Iniciar sesión
2. Leer los precios del catálogo
3. Seleccionar Price (low to high)
4. Leer de nuevo los precios

### Resultado esperado
Los precios se muestran en orden ascendente.
